ORACLE: Agentic AI Orchestrator Routing Via Adaptive Verifier Calibration Feedback
    Ritik Raj, Souvik Kundu, Dheemanth Joshi, Tushar Krishna arXiv preprint arXiv:2607.22465
    Summary Paper Code

    Summary

    ORACLE adapts model routing and task-specific verification for concurrent agent workloads. Delayed verifier feedback reduces dispatch delays, while a companion scheduler accounts for KV-memory demand and backend wait times. Earlier versions appeared as TRACE-Router.
