Serving Agentic Workflows with a Physical-Plan Compiler and Adaptive Runtime
    Jiayi Qian, Yichong Zhang, Hanchen Yang, Chun Tao, Souvik Kundu, Zishen Wan, Tushar Krishna arXiv preprint arXiv:2607.02942
    Summary Paper

    Summary

    Dyserve jointly plans model choices, verification, and serving backends for agent workflows. A profile-guided compiler prepares alternative plans, and the runtime switches undispatched work as backend load changes. Earlier versions appeared as A Workflow-Aware Serving Layer for Agentic Applications.
