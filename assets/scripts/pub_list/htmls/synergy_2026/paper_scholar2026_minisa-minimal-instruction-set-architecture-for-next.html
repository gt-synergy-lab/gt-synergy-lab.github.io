MINISA: Minimal Instruction Set Architecture for Next-gen Reconfigurable Inference Accelerator
    Jianming Tong, Devansh Jain, Yujie Li, Charith Mendis, Tushar Krishna ISPASS 2026
    Abstract Paper
    fpga accelerators dataflow systems

    Abstract

    MINISA proposes a minimal instruction set to efficiently program a reconfigurable inference accelerator at virtual-neuron granularity while reducing off-chip configuration overhead.
