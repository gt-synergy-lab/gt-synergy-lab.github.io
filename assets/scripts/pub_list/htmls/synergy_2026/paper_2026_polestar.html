Polestar: Drift-Aware Cache Calibration and Token Commitment for Efficient Inference of Diffusion LLMs
    Mingyu Lee, Akshat Ramachandran, Souvik Kundu, Tushar Krishna NeurIPS 2026
    Summary Paper

    Summary

    Polestar uses changes in token representations to guide both KV-cache refreshes and token commitment during diffusion LLM inference. This shared signal allows greater decoding parallelism while preserving output quality, without additional model training.
