ThunderAgent: A Fast, Simple, and Program-Aware Agentic Inference System
    Hao Kang, Ziyang Li, Xinyu Yang, Weili Xu, Yinfang Chen, Junxiong Wang, Beidi Chen, Tushar Krishna, Chenfeng Xu, Simran Arora ICML 2026
    Abstract Paper

    Abstract

    ThunderAgent is a program-aware agentic inference system that schedules and manages LLM KV cache and tool environments to improve throughput and resource efficiency.
