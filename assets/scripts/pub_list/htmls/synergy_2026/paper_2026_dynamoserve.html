DynamoServe: A Distributed Tiered Memory System for Multi-tenant LLM Serving
    Diman Zad Tootaghaj, Khaled Diab, Bob Lantz, Hanjiang Wu, K. K. Ramakrishnan, Md Ashfaqur Rahaman, Ryan Stutsman, Puneet Sharma, Tushar Krishna SIGCOMM 2026
    Summary Paper

    Summary

    DynamoServe uses otherwise idle GPU memory to hold model weights and KV caches for multi-tenant LLM inference. Coordinated placement and on-demand migration reduce memory fragmentation and improve locality across GPUs.
